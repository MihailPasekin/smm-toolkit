# SMM Toolkit

Создавай Shorts/Reels из длинных видео за 2 минуты вместо 2 часов.

## Что делает
- Скачивает видео с YouTube/TikTok/Instagram
- Нарезает на равные части (30/60/90 сек)
- Автоматически делает вертикальный формат 9:16
- Создаёт субтитры на 99+ языках
- Накладывает субтитры на видео

## Установка (5 минут)

```bash
# 1. Установи ffmpeg и yt-dlp
brew install ffmpeg yt-dlp

# 2. Установи Python зависимости
pip install -r requirements.txt
